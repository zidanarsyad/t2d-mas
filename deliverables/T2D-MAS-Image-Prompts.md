# T2D-MAS deck: image prompts

The deck's diagrams are native PowerPoint shapes and charts, so you can edit them directly. These
prompts are for optional illustrations that shapes cannot draw well: small spot icons and two
concept pictures. Paste a prompt into an image generator (for example Gemini, ChatGPT or Canva),
then place the result as described. Slide numbers refer to the 20-slide deck.

## Shared style

Add this to the end of every prompt, so all images look like one set:

```text
Flat vector illustration, clean and minimal, thick rounded strokes. Use only deep navy #01416B and
warm yellow #FDD402, with light blue #E6EEF5 as a soft accent, on a plain white background. No text,
no letters, no numbers, no logos, no watermark. Leave empty space around the subject.
```

Tips:
- Generate each set in one session, so the style stays the same.
- Ask for a PNG; a transparent background is best if the tool offers it.
- If you use generated images, add a line to slide 19 (Sources), for example: "Illustrations generated with Gemini."

## 3. The mobile agent idea (optional divider before slide 12)

**Placement:** a new slide titled "Mobile agents", placed before slide 12, with this image on the
right half (about 6 × 4.5 inches, aspect ratio 4:3).

```text
Side view, left to right: a small friendly courier robot carries a sealed parcel with a yellow
seal into a row of six server racks. Large, heavy crates stay on the server shelves. On the way
out, the robot carries only a tiny envelope.
```

**Alt text:** A courier robot brings sealed code to the servers and leaves with a small envelope;
the large data crates stay where they are.

## 4. People stay in control (optional divider before the live demo)

**Placement:** a new slide titled "Live demo" placed before the demo starts, with this image on the
right half (about 6 × 4.5 inches, aspect ratio 4:3).

```text
Isometric view of a calm office: a small team of friendly software robots at a control desk hands
a ticket card to a human reviewer, who holds a large approval stamp.
```

**Alt text:** Software agents prepare the work, and a person makes the final decision.
